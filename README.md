# ✈️ Tripora — Explore Beyond

### A Smart Travel Planning Desktop Application

Tripora is a Python-based desktop travel planning application built using Tkinter. It helps users explore destinations, create personalized travel itineraries, save trip plans, and estimate travel budgets through a clean and intuitive graphical interface.

The project focuses on making travel planning simple, organized, and accessible through a local-first desktop experience.

## ✨ Features

### 🌍 Destination Explorer
- Explore curated travel destinations.
- View destination descriptions, ratings, highlights, and estimated budgets.
- Browse destinations by travel category.
- Search and filter destinations.

### 🧭 Trip Planner
- Create personalized travel plans.
- Select destination, travel date, duration, and number of travellers.
- Set a preferred budget and travel pace.
- Choose travel interests such as nature, adventure, culture, and local food.
- Generate suggested itineraries.

### 📌 My Itineraries
- Save created travel plans locally.
- View previously saved itineraries.
- Revisit trip details.
- Delete saved travel plans.

### 💰 Budget Planner
- Estimate accommodation expenses.
- Calculate food and activity costs.
- Include transportation expenses.
- Calculate an estimated overall trip budget.

### 🎨 User Interface
- Modern desktop dashboard.
- Sidebar-based navigation.
- Destination cards and visual illustrations.
- Local image asset support.
- Clean and user-friendly layout.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/SahilSingh2507/Tripora.git
```

### 2. Navigate to the project directory

```bash
cd Tripora
```

### 3. Create a virtual environment (recommended)

```bash
python3 -m venv venv
```

Activate it on macOS/Linux:

```bash
source venv/bin/activate
```

### 4. Install dependencies

```bash
python3 -m pip install -r requirements.txt
```

### 5. Run the application

```bash
python3 main.py
```

## 💾 Data Storage

Tripora stores saved travel itineraries locally in a JSON file in the user's home directory.

This allows users to retain their saved trip plans between application sessions without requiring a remote database.
